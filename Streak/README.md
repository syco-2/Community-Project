# Streak

Streak is a small habit tracker for one person. You keep up to five habits, each with a
name you choose, and mark them off when the day is done. Every habit counts its own days
in a row, and the count stops as soon as a day is missed, so the number on screen is the
real run and not an estimate.

A tap on the circle marks a habit for today, a second tap takes the mark back. The count
sits next to the name and turns yellow while a run is alive. Under the list is the month
view: every day of the month in a grid, a day where all habits are marked is filled blue,
a day with only some marked is lighter, and today carries a ring. The arrows step through
the months, so you can look back at the start of a run or check a week you are unsure
about. A habit can be removed at any time, which frees its slot for a new one.

The app opens on today and needs no setup, no account and no plan import. Everything is
stored on the device: the habits, the marks and the counts live in the browser storage on
the web version and in local storage on the phone. There is no sync, no cloud and no
server, and the app has no permission to reach the internet.
